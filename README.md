# 璟策 — 珠宝门店界面 Demo

三个静态页面展示经营看板、周期任务和经营分析的界面概念。数据、诊断、责任人和预估收益都是写在页面中的示例，没有后端、模型调用或真实派单。

## 查看

直接打开 `index.html`，或从仓库根目录启动本地服务器：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

访问 `http://127.0.0.1:4173/index.html`。

| 页面 | 文件 |
| --- | --- |
| 经营看板 | `index.html` |
| 周期任务 | `tasks.html` |
| 经营分析 | `ai-review.html` |

`styles.css` 提供共享样式，`app.js` 处理分段按钮的选中状态和移动端菜单。分段切换主要是视觉反馈，未连接数据筛选服务。

## 实现范围

项目用于界面浏览和方案沟通。页面中的“AI归因”“自动生成动作”和“证据验收”描述产品概念，不是已执行的业务链路；没有持久化任务、权限、效果评估或业务数据接入。

六个项目文件已经覆盖当前静态用途，无需构建工具或依赖目录。
